1º semestre

Desenvolvimento Web I

Fundamentos para criar páginas, organizar o conteúdo, trabalhar o visual e adicionar comportamento no navegador.

01

HTML e semântica

Estrutura de páginas, textos, links, imagens, listas, tabelas, formulários e uso de elementos semânticos.

02

CSS e layouts

Cores, tipografia, espaçamentos, box model, posicionamento e construção de páginas responsivas.

03

Bootstrap

Grid responsivo, componentes prontos, navegação e adaptação do layout para diferentes telas.

04

JavaScript

Variáveis, funções, eventos, cálculos e manipulação do conteúdo da página.

05

Formulários e APIs

Validação de dados, jQuery, consulta de CEP e consumo de informações de serviços externos.

06

Armazenamento local

Uso do localStorage para manter dados no navegador e apoiar pequenas aplicações web.

1º semestre

Design Digital

Decisões visuais e de interação para comunicar melhor e construir experiências mais fáceis de usar.

01

IHC e interfaces

Interação entre pessoas e sistemas, evolução das interfaces e importância de considerar diferentes perfis de usuário.

02

Usabilidade

Efetividade, eficiência e satisfação, com aplicação das dez heurísticas de Jakob Nielsen.

03

Tipografia

Anatomia dos tipos, famílias tipográficas, legibilidade, alinhamento, espaçamento e escolha adequada ao projeto.

04

Design Thinking

Empatia, definição do problema, ideação, prototipação e teste com usuários.

1º semestre

Sistemas Operacionais e Redes

Fundamentos de Linux e redes para entender melhor o ambiente onde os sistemas são executados e conectados.

01

Linux e virtualização

Instalação, particionamento, Live CD, máquinas virtuais e uso inicial do sistema.

02

Terminal e arquivos

Comandos, diretórios, cópia, movimentação, remoção, redirecionamento e leitura de arquivos de texto.

03

Usuários e permissões

Usuários, grupos, propriedade, permissões simbólicas e octais, chmod e chown.

04

Rede e acesso remoto

Configuração de interface e IP, rede em modo bridge e conexão SSH com PuTTY.

2º semestre

Desenvolvimento Web II

Construção de aplicações completas, ligando frontend, backend, banco de dados e APIs.

01

Arquitetura web

Modelo cliente-servidor, HTTP, organização das camadas e integração entre frontend e backend.

02

Spring Boot e Maven

Criação de projetos Java, dependências, configuração e execução de aplicações web.

03

MVC e APIs REST

Separação em model, repository, service e controller, rotas e operações CRUD.

04

Persistência

JPA, mapeamento objeto-relacional, conexão com MySQL e testes de endpoints com Postman.

05

React

Componentes, JSX, propriedades, estado, eventos, formulários, listas, rotas e renderização condicional.

06

Integração full stack

Fetch, useEffect e consumo da API do Spring Boot por uma interface React.
